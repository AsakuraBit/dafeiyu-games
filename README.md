# 大肥鱼的游戏小屋 / 大肥魚のゲーム小屋

浏览器里就能玩的小游戏合集。**不用下载、不用安装，点开网址就玩。**
ブラウザで遊べるミニゲーム集。ダウンロード不要です。

---

## 🎮 游戏列表

### [大肥鱼 · 星海射击](games/star-shooter.html)
**大肥魚 · 星海シューティング**

一条蓝鱼的太空保卫战。鼠标移动控制方向、点击开火，敌人一波波从上方涌下来。
青い魚の宇宙防衛戦。マウスで移動、クリックで発射。

- 🖱 **移动鼠标** 鱼跟着走，炮口自动朝鼠标转
- 🖱 **点击左键** 开火（按住不放 = 连射）
- ⌨️ **空格** 暂停 / 继续　**R** 重来　**M** 静音　**L** 切换语言
- 🌐 **支持中文 / 日本語**，开局可选，游戏中按 `L` 随时切换

**敌人**：杂兵、🛡盾兵（打两下）、⚠️冲撞兵（会追你）、🟢炮手（吐弹）、👑舰长（每 4 波一只，会俯冲）

## 怎么自己跑

## 部署说明（给大肥鱼自己看）

这是 GitHub Pages 的发布目录，结构：

```
index.html                    游戏列表首页
games/star-shooter.html       游戏本体（单文件）
```

推送到仓库的 `main` 分支后，在 Settings → Pages 里选 `main` 分支根目录即可。
